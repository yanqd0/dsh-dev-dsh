# 版本维度：基准、极简 CHANGELOG 与差分页

> 本文是 `references/dsh/index.md` 的子页。

**当前基准**：`deepseek-harness@dsh-v0.2.0-rc.2`（与本机运行时一致）。
**全手册只有本页声明基准**——其它页面只保留一条 provenance pin，不写「当前 / 与本机一致」。

版本知识按**大版本线**组织：0.2.0 是默认基准，0.1.7 与 0.1.5 是两条历史线。同一线内 rc / alpha 之间的微差
**不研究、不立页**（台账仍按具体 tag 记 `source`）。

## 差分页命名与内容契约

- 命名：`references/dsh/versions/<历史线>-to-<基准线>.md`，版本串必须 kebab-safe（点号违反 skill 命名契约）：
  从 `0.1.7` 到 `0.2.0` 的一页写成 `0-1-7-to-0-2-0.md`。
- 一页只覆盖「一条历史线 → 基准线」，不把多条历史线合并成一大页；内容过多时该页升格为同名目录 +
  `index.md` + 主题页。
- 每页回链本索引，形态是**反 CHANGELOG**，固定回答四问：
  1. 改了什么、删了什么；
  2. 历史插件为什么在它上面坏；
  3. 升级要动哪些文件与字段；
  4. 有哪些写法会静默失效（这类最贵，优先写）。

## 纪律

- 每页声明事实 pin；台账自动复核一次只覆盖一个本地 checkout 版本，历史差分靠人工对照
  （`notes/skill-design.md` §6）。
- 想加新版本线：先写差分页并在此表登记，再重校受影响页的 pin。
