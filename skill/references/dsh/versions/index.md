## 差分页命名契约

- 命名：`references/dsh/versions/<from>-to-<to>.md`，版本串必须 kebab-safe（点号违反 skill 命名契约）：
  从 `0.1.7-rc.2` 到 `0.2.0-rc.1` 的一页写成 `0-1-7-rc-2-to-0-2-0-rc-1.md`。
- 每页回链本索引，形态是**反 CHANGELOG**，固定回答四问：
  1. 这个版本改了什么、删了什么；
  2. 历史插件为什么在它上面坏；
  3. 升级要动哪些文件与字段；
  4. 有哪些写法在新版本会静默失效（这类最贵，优先写）。
- 一页只覆盖一对相邻版本；跨多版本不合并成一大页。
- 当前待写的两页（plan #19）：`0-1-7-rc-2-to-0-2-0-rc-1.md`、`0-2-0-rc-1-to-0-2-0-rc-2.md`。

## 纪律

- 每页声明事实 pin；台账自动复核一次只覆盖一个本地 checkout 版本，历史差分靠人工对照
  （`notes/skill-design.md` §6）。
- 想加新版本：先写差分页并在此表登记，再重校受影响页的 pin。
